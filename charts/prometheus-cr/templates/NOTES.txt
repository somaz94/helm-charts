IMPORTANT: creating these CRs is not enough on its own — your Prometheus must
SELECT them. Check the Prometheus CR's serviceMonitorSelector / podMonitorSelector
/ ruleSelector / probeSelector / scrapeConfigSelector (and the matching
*NamespaceSelector). With kube-prometheus-stack, either add the label its
selector expects to `commonLabels`, or set the relevant
`*SelectorNilUsesHelmValues: false` so it selects all resources cluster-wide.

NOTE: This chart only creates monitoring *config* CRs. The Prometheus Operator
and its CRDs must already be installed — typically via kube-prometheus-stack or
the prometheus-operator chart.
